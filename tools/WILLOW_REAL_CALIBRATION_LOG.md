# Willow 实机动力学标定记录

本文记录 Willow 实机标定的操作顺序、命令、结果和证据边界，并随实验持续更新。

## 1. 静态重力标定（已完成）

### 实验方法

- J1 保持启动时实测编码器角度，不命令到编码器零位。
- J2/J3 使用离散姿态组合，J4–J6 使用安全范围内的离散姿态。
- 机械臂通过 MIT 位置控制到达目标，等待本体静止后记录反馈关节角和反馈力矩。
- 共保存 200 个真实静态姿态，数据用于优化各连杆质量与质心。
- 固件重力补偿关闭；验证阶段仅发送 Pinocchio 根据优化 URDF 计算的 `g(q)` 力矩前馈。

### 当前正式模型

`assets/urdf/Ragtime_Willow_static_mass_com_calibrated.urdf`

SHA256：

```text

```

### 实机结果

- 200 姿态静态质量/质心拟合已完成。
- 关闭固件重力补偿后，纯 Pinocchio `g(q)` 前馈能够稳定支撑机械臂。
- 操作者进一步验证关节阻尼全部设为 0 时仍可稳定保持。
- 该结果证明当前静态质量/质心模型已具备可用的重力补偿效果。
- 它不等同于摩擦、执行器反射惯量或完整动态惯性参数已经标定。

## 2. 摩擦标定（进行中）

### 目标

逐轴辨识并比较：

1. 对称库仑摩擦 + 黏性摩擦 + 常值偏置；
2. 正负方向独立的非对称库仑/黏性模型；
3. Stribeck + 库仑 + 黏性 + 常值偏置。

J2–J6 为必需数据；J1 因安装零位可变化，使用相对启动角的独立可选实验。

### 路径碰撞预审（已完成）

运行命令：

```bash
conda activate willow-calib
cd ~/projects/libflorid-main/tools/friction_calibration
python preview_hppfcl.py
```

该命令不访问 USB，也不发送机械臂指令。它用 Pinocchio + HPP-FCL 对训练与 held-out
两套支撑姿态下的 J2–J6 扫描路径分别检查 401 个离散姿态，共 4010 个姿态。

2026-08-29 实际结果：

| 关节 | 扫描范围 | 训练最小净距 | held-out 最小净距 |
|---|---:|---:|---:|
| J2 | 30°～90° | 6.222 mm | 6.222 mm |
| J3 | 45°～100° | 6.222 mm | 6.222 mm |
| J4 | -50°～50° | 6.222 mm | 6.222 mm |
| J5 | -10°～10° | 5.744 mm | 5.744 mm |
| J6 | -50°～50° | 5.757 mm | 5.757 mm |

全部姿态均满足非相邻连杆净距不小于 5 mm，程序退出码为 0。Pinocchio 关于
`package_dirs` 的 `UserWarning` 不影响计算结果。

### 必需采集顺序

1. `run_friction_collection.py`：正反向 2/5/10/20°/s 恒速数据。
2. `run_low_speed_stribeck_collection.py`：正反向 0.5/1°/s 低速数据。
3. `run_breakaway_collection.py`：正反方向缓慢增力矩的启动摩擦数据。
4. `fit_friction.py`：离线比较三类模型，训练 repeat 做 grouped-CV，repeat 2 仅作独立验证。

恒速、低速和 breakaway 均按 J2→J3→J4→J5→J6 连续分块。采集文件逐 trial
原子保存，中断重启会跳过已经完成的 trial。正式采集前必须先保持
`ENABLE_HARDWARE=False` 运行禁用预览；确认设计后只修改当前入口为 `True`，并输入其专用确认短语。
